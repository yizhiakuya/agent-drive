# 文件整理器

当用户要求整理/归档/分类网盘文件时使用本技能。

## 步骤

1. **读偏好**：先用 `get_system_status` 查看用户整理偏好（organize_style / naming_rule）
2. **扫描现状**：递归 `list_files`，列出所有文件和目录
3. **设计分类方案**：按偏好设计目录结构（如按项目名/按文件类型/按日期）
4. **移动文件**：用 `move_file` 逐个移动，每个操作后确认成功
5. **汇报**：列出整理前后对比（移动了哪些文件、新目录结构）

## 分类规则建议
- 文档类（.txt/.md/.pdf/.docx）→ `文档/`
- 图片类（.jpg/.png/.gif）→ `图片/`
- 代码类（.py/.js/.ts）→ `代码/`
- 其他 → 按文件名前缀分组

## 注意事项
- 移动前先 `create_folder` 建好目标目录
- 不要移动已经分类好的文件（避免重复整理）
- 同名文件冲突时：在目标名后加序号（file_2.txt），不要覆盖
- 每次移动后检查结果（Critic 会自动验证）
