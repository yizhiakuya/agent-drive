# 周报生成器

当用户要求生成周报/工作总结时使用本技能。

## 步骤

1. **扫描文件**：用 `list_files` 列出网盘所有目录（递归），记录每个文件的 `mtime`（修改时间）
2. **筛选本周**：`mtime` 在最近 7 天内的文件 = 本周工作内容
3. **提取要点**：对每个本周文件用 `read_file` 读取内容（文本文件），提取 1 句核心要点
4. **生成周报**：按此格式输出：

```
## 本周工作周报（{日期范围}）

### 一、本周工作内容
1. 【{文件/目录名}】{核心要点}
2. ...

### 二、文件变更统计
- 新增/修改文件：{N} 个
- 主要涉及目录：{列表}

### 三、下周建议
（基于未完成事项/文件状态给出 1-2 条建议）
```

## 注意事项
- 文件时间用 `mtime` 字段判断，不要凭内容猜测
- 二进制文件（无法 read_file）只列名称不提取要点
- 没有本周文件时，明确告诉用户"本周暂无文件变更"并展示最近的文件
- 用户可指定日期范围："本周"默认最近 7 天
